Nós gostamos de ter um histórico de projeto limpo. Nossa convenção de commits é inspirada por [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0), mas personalizada com [gitmoji](https://gitmoji.dev) para torná-la mais visual e divertida.

## Estrutura

A mensagem de commit deve ser estruturada da seguinte forma e **em minúsculas**:

```
<gitmoji> <tipo> <descrição> [(#<número do issue>)]
 
[corpo opcional]

[rodapé(s) opcional(is)]
```

### Exemplo

```bash
📝 atualizar contribuidores da documentação

- Adicionar @jerembdn como um contribuinte
- Adicionar @younesbessa como um contribuinte

Co-autorado por: Younes Bessa <younes@onruntime.com>
```

Na maioria das vezes, uma linha simples é suficiente:

```bash
📝 atualizar contribuidores da documentação
```

## Tipos

Nós usamos os seguintes tipos de commit:

| Tipo | Descrição |
| --- | --- |
| `add` | Adicionar uma nova funcionalidade |
| `fix` | Corrigir um bug |
| `improve` | Melhorar algo |
| `update` | Atualizar algo |
| `remove` | Remover algo |
| `refactor` | Refatorar algo |
| `rename` | Renomear algo |
| `move` | Mover um arquivo ou pasta |
| `upgrade` | Atualizar dependências |
| `downgrade` | Rebaixar dependências |
| `initial` | Commit inicial de um repositório |
| `release` | Lançamento / tag de versão |

O primeiro commit de um repositório usa `initial`, e uma tag de versão usa
`release`:

```bash
🎉 commit inicial
🔖 lançamento @onruntime/translations v0.3.0
```

## Descrição

O `<tipo>` é o verbo do assunto, e a descrição o completa. Lidos juntos, eles formam **uma frase**:

```bash
# Bom
📝 atualizar contribuidores da documentação
```

Então não comece a descrição com um segundo verbo. O tipo já é um, e
o assunto acaba empilhando duas frases, que é o que um prefixo `fix:` leva a. Elimine o verbo e mantenha o que ele agia:

```bash
# Ruim
💄 melhorar a escala do gem no seu cartão
🐛 consertar o rodapé para não quebrar

# Bom
💄 melhorar o tamanho do gem no seu cartão
🐛 consertar o rodapé quebrando
```

Escreva no **modo imperativo** e **em minúsculas**:

```bash
# Ruim
📝 atualizado contribuidores da documentação

# Ruim
📝 Atualizar contribuidores da documentação
```

<Callout type="info" title="Um Verbo Que É um Substantivo">
  Algumas palavras são ambas, e a que você quer dizer é o substantivo: `✨ adicionar imagem open graph` está certo. Quando ler como um verbo, um artigo transforma em uma expressão substantiva novamente: `✨ adicionar um botão mostrar mais`.
</Callout>

## Número do Issue

Vincule commits a issues adicionando o número do issue:

```bash
📝 atualizar contribuidores da documentação (#123)
```

## Corpo

Use o corpo para contexto e motivação:

```bash
📝 atualizar contribuidores da documentação

- Adicionar @jerembdn como um contribuinte
- Adicionar @younesbessa como um contribuinte

Co-autorado por: Younes Bessa <younes@onruntime.com>
```

<Callout type="info" title="Um Commit, Um Propósito">
  Cada commit deve representar uma única mudança lógica. Não misture mudanças não relacionadas.
</Callout>
