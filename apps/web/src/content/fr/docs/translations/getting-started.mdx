## Qu'est-ce que @onruntime/translations ?

`@onruntime/translations` est une bibliothèque légère et sécurisée pour l'internationalisation (i18n) conçue pour les applications React et Next.js. Elle offre une API simple pour gérer les traductions avec un support complet de TypeScript.

<Callout type="info" title="Fonctionnalités Clés">
  - Traductions sécurisées avec TypeScript
  - Support pour React et Next.js (App Router)
  - Organisation basée sur les espaces de noms
  - Interpolation de variables
  - Pluriels et accords grammaticaux via ICU `plural` et `select`
  - Léger et performant
</Callout>

## Pourquoi l'utiliser ?

### Sécurité de Type

Obtenez des erreurs à la compilation lorsque vous utilisez des clés de traduction invalides :

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ Clé valide
t("invalid_key");     // ❌ Erreur TypeScript
```

### API Simple

Juste deux hooks pour tous vos besoins de traduction :

```typescript
// Composants Client
const { t } = useTranslation("namespace");

// Composants Serveur (Next.js)
const { t } = await getTranslation("namespace");
```

### Traductions Organisées

Gardez vos traductions organisées avec des espaces de noms :

## Exemple Rapide

```tsx
// locales/en/common.json
{
  "greeting": "Hello, {name}!"
}

// Composant
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
