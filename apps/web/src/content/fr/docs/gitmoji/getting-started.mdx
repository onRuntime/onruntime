Nous aimons avoir un historique de projet propre. Notre convention de commits est inspirée par [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0) mais personnalisée avec [gitmoji](https://gitmoji.dev) pour rendre ça plus visuel et amusant.

## Structure

Le message de commit doit être structuré comme suit et **en minuscules** :

```
<gitmoji> <type> <description> [(#<numéro de l'incident>)]

[corps optionnel]

[pied(s) optionnel(s)]
```

### Exemple

```bash
📝 mettre à jour les contributeurs de la documentation

- Ajouter @jerembdn comme contributeur
- Ajouter @younesbessa comme contributeur

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

La plupart du temps, une simple ligne suffit :

```bash
📝 mettre à jour les contributeurs de la documentation
```

## Types

Nous utilisons les types de commits suivants :

| Type | Description |
| --- | --- |
| `add` | Ajouter une nouvelle fonctionnalité |
| `fix` | Corriger un bug |
| `improve` | Améliorer quelque chose |
| `update` | Mettre à jour quelque chose |
| `remove` | Supprimer quelque chose |
| `refactor` | Refactoriser quelque chose |
| `rename` | Renommer quelque chose |
| `move` | Déplacer un fichier ou un dossier |
| `upgrade` | Mettre à niveau les dépendances |
| `downgrade` | Rétrograder les dépendances |
| `initial` | Commit initial d'un dépôt |
| `release` | Release / tag de version |

Le premier commit d'un dépôt utilise `initial`, et un tag de version utilise
`release` :

```bash
🎉 commit initial
🔖 release @onruntime/translations v0.3.0
```

## Description

Écrivez des descriptions à l'**impératif** et **en minuscules** :

```bash
# Bien
📝 mettre à jour les contributeurs de la documentation

# Mal
📝 mis à jour les contributeurs de la documentation

# Mal
📝 Mettre à jour les contributeurs de la documentation
```

## Numéro d'incident

Liez les commits aux incidents en ajoutant le numéro d'incident :

```bash
📝 mettre à jour les contributeurs de la documentation (#123)
```

## Corps

Utilisez le corps pour le contexte et la motivation :

```bash
📝 mettre à jour les contributeurs de la documentation

- Ajouter @jerembdn comme contributeur
- Ajouter @younesbessa comme contributeur

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

<Callout type="info" title="Un Commit, Un But">
  Chaque commit doit représenter un changement logique unique. Ne mélangez pas les changements non liés.
</Callout>
