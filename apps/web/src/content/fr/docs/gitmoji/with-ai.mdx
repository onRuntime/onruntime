Installe notre plugin gitmoji pour [Claude Code](https://claude.ai/code) afin de générer des commits suivant la convention.

## Installer le Plugin

Ajoute le marketplace onRuntime et installe le plugin :

```bash
# Ajouter le marketplace onRuntime
/plugin marketplace add https://onruntime.com/plugins

# Installer le plugin gitmoji
/plugin install gitmoji@onruntime
```

Ou installe directement depuis le menu :

1. Exécute `/plugin` dans Claude Code
2. Va dans l’onglet **Découvrir**
3. Ajoute le marketplace : `https://onruntime.com/plugins`
4. Cherche "gitmoji" et installe

## Utilisation

Exécute la commande `/commit` pour créer un commit :

```
/commit
```

```
/commit fix le bug de connexion
```

Claude Code analysera tes changements et créera un commit suivant la convention gitmoji.

<Callout type="info" title="Commande du Plugin">
  La commande `/commit` récupère automatiquement ton statut git et le diff pour générer le message de commit approprié.
</Callout>

## Alternative : CLAUDE.md

Si tu préfères ne pas installer le plugin, ajoute ceci à ton `CLAUDE.md` de projet :

````markdown
## Convention de Commit

Utilise les commits conventionnels gitmoji :

```
<gitmoji> <type> <description>
```

Types : add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

Règles :
- Écris en minuscules
- Le type est le verbe du sujet et la description le complète en une
  phrase. Reste à l'impératif ("add" pas "added")
- N'ouvre jamais la description avec un second verbe : "fixe le footer qui se plie", pas
  "fixe arrêter le footer de se plier"
- Un changement logique par commit
````
