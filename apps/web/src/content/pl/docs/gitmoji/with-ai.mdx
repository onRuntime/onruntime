Zainstaluj naszą wtyczkę gitmoji dla [Claude Code](https://claude.ai/code), aby generować commity zgodnie z konwencją.

## Zainstaluj wtyczkę

Dodaj rynek onRuntime i zainstaluj wtyczkę:

```bash
# Dodaj rynek onRuntime
/plugin marketplace add https://onruntime.com/plugins

# Zainstaluj wtyczkę gitmoji
/plugin install gitmoji@onruntime
```

Lub zainstaluj bezpośrednio z menu:

1. Uruchom `/plugin` w Claude Code
2. Przejdź do zakładki **Discover**
3. Dodaj rynek: `https://onruntime.com/plugins`
4. Szukaj "gitmoji" i zainstaluj

## Użytkowanie

Uruchom polecenie `/commit`, aby stworzyć commit:

```
/commit
```

```
/commit fix the login bug
```

Claude Code przeanalizuje Twoje zmiany i stworzy commit zgodnie z konwencją gitmoji.

<Callout type="info" title="Polecenie Wtyczki">
  Polecenie `/commit` automatycznie pobiera Twój status git i różnice, aby wygenerować właściwą wiadomość commit.
</Callout>

## Alternatywa: CLAUDE.md

Jeśli wolisz nie instalować wtyczki, dodaj to do `CLAUDE.md` swojego projektu:

````markdown
## Konwencja Commitów

Używaj konwencjonalnych commitów gitmoji:

```
<gitmoji> <typ> <opis>
```

Typy: add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

Zasady:
- Pisz małymi literami
- Typ to czasownik podmiotu, a opis uzupełnia go w jedno
  zdanie. Utrzymuj to w trybie rozkazującym ("add" nie "added")
- Nigdy nie zaczynaj opisu od drugiego czasownika: "fix the footer wrapping", nie
  "fix stop the footer from wrapping"
- Jedna logiczna zmiana na commit
````
