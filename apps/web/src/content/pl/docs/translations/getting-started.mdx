## Czym jest @onruntime/translations?

`@onruntime/translations` to lekkiej wagi, bezpieczna dla typów biblioteka internacjonalizacji (i18n) zaprojektowana do aplikacji React i Next.js. Oferuje prosty interfejs API do zarządzania tłumaczeniami z pełnym wsparciem TypeScript.

<Callout type="info" title="Kluczowe Funkcje">
  - Tłumaczenia bezpieczne dla typów z TypeScript
  - Wsparcie dla React i Next.js (App Router)
  - Organizacja oparta na przestrzeniach nazw
  - Interpolacja zmiennych
  - Liczby mnogie i zgodność gramatyczna dzięki ICU `plural` i `select`
  - Lekka i wydajna
</Callout>

## Dlaczego warto to używać?

### Bezpieczeństwo Typów

Uzyskaj błędy w czasie kompilacji, gdy używasz nieważnych kluczy tłumaczeń:

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ Prawidłowy klucz
t("invalid_key");     // ❌ Błąd TypeScript
```

### Prosty Interfejs API

Tylko dwa hooki do wszystkich Twoich potrzeb tłumaczeniowych:

```typescript
// Komponenty Klientów
const { t } = useTranslation("namespace");

// Komponenty Serwera (Next.js)
const { t } = await getTranslation("namespace");
```

### Zorganizowane Tłumaczenia

Utrzymuj swoje tłumaczenia zorganizowane z przestrzeniami nazw:

<Files>
  <Folder name="locales" defaultOpen>
    <Folder name="en" defaultOpen>
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
    <Folder name="fr">
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
  </Folder>
</Files>

## Szybki Przykład

```tsx
// locales/en/common.json
{
  "greeting": "Hello, {name}!"
}

// Komponent
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
