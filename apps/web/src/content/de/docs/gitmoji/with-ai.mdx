Installiere unser gitmoji Plugin für [Claude Code](https://claude.ai/code), um Commits gemäß der Konvention zu erstellen.

## Installiere das Plugin

Füge den onRuntime Marktplatz hinzu und installiere das Plugin:

```bash
# Füge den onRuntime Marktplatz hinzu
/plugin marketplace add https://onruntime.com/plugins

# Installiere das gitmoji Plugin
/plugin install gitmoji@onruntime
```

Oder installiere direkt über das Menü:

1. Führe `/plugin` in Claude Code aus
2. Gehe zum Tab **Entdecken**
3. Füge den Marktplatz hinzu: `https://onruntime.com/plugins`
4. Suche nach "gitmoji" und installiere es

## Nutzung

Führe den Befehl `/commit` aus, um einen Commit zu erstellen:

```
/commit
```

```
/commit fix den Login-Bug
```

Claude Code analysiert deine Änderungen und erstellt einen Commit gemäß der gitmoji Konvention.

<Callout type="info" title="Plugin Befehl">
  Der Befehl `/commit` ruft automatisch deinen Git-Status und Diff ab, um die passende Commit-Nachricht zu generieren.
</Callout>

## Alternative: CLAUDE.md

Wenn du das Plugin nicht installieren möchtest, füge dies zu deiner Projektdatei `CLAUDE.md` hinzu:

````markdown
## Commit-Konvention

Nutze gitmoji konventionelle Commits:

```
<gitmoji> <type> <beschreibung>
```

Arten: add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

Regeln:
- Schreibe in Kleinbuchstaben
- Der Typ ist das Verb des Subjekts, und die Beschreibung vervollständigt es zu einem
  Satz. Halte es imperativ ("add" nicht "added")
- Öffne die Beschreibung niemals mit einem zweiten Verb: "fix den Footer-Wrap", nicht
  "fix stop den Footer vom Wrap"
- Eine logische Änderung pro Commit
````
