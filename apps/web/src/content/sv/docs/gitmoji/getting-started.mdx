Vi gillar att ha en ren projektlogg. Vår commit-konvention är inspirerad av [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0) men anpassad med [gitmoji](https://gitmoji.dev) för att göra det mer visuellt och roligt.

## Struktur

Commit-meddelandet ska struktureras enligt följande och **i gemener**:

```
<gitmoji> <typ> <beskrivning> [(#<ärendenummer>)]

[valfritt brödtext]

[valfria fotnoter]
```

### Exempel

```bash
📝 uppdatera dokumentation bidragsgivare

- Lägg till @jerembdn som en bidragsgivare
- Lägg till @younesbessa som en bidragsgivare

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

Mestadels av tiden räcker det med en enkel rad:

```bash
📝 uppdatera dokumentation bidragsgivare
```

## Typer

Vi använder följande commit-typer:

| Typ | Beskrivning |
| --- | --- |
| `add` | Lägg till en ny funktion |
| `fix` | Fixa en bugg |
| `improve` | Förbättra något |
| `update` | Uppdatera något |
| `remove` | Ta bort något |
| `refactor` | Refaktorera något |
| `rename` | Byt namn på något |
| `move` | Flytta en fil eller mapp |
| `upgrade` | Uppgradera beroenden |
| `downgrade` | Nedgradera beroenden |
| `initial` | Första commit av ett repository |
| `release` | Release / versionsetikett |

Den första commit av ett repository använder `initial`, och en versionsetikett använder
`release`:

```bash
🎉 första commit
🔖 release @onruntime/translations v0.3.0
```

## Beskrivning

Skriv beskrivningar i **imperativ form** och **gemener**:

```bash
# Bra
📝 uppdatera dokumentation bidragsgivare

# Dåligt
📝 uppdaterade dokumentation bidragsgivare

# Dåligt
📝 Uppdatera dokumentation bidragsgivare
```

## Ärendenummer

Länka commits till ärenden genom att lägga till ärendenumret:

```bash
📝 uppdatera dokumentation bidragsgivare (#123)
```

## Brödtext

Använd brödtexten för kontext och motivation:

```bash
📝 uppdatera dokumentation bidragsgivare

- Lägg till @jerembdn som en bidragsgivare
- Lägg till @younesbessa som en bidragsgivare

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

<Callout type="info" title="En Commit, Ett Syfte">
  Varje commit bör representera en enda logisk förändring. Blanda inte orelaterade förändringar.
</Callout>
