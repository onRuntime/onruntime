Vi gillar att ha en ren projekt historia. Vår commits konvention är inspirerad av [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0) men anpassad med [gitmoji](https://gitmoji.dev) för att göra det mer visuellt och roligt.

## Struktur

Commit-meddelandet ska struktureras enligt följande och **i gemener**:

```
<gitmoji> <typ> <beskrivning> [(#<ärendenummer>)]

[valfri kropp]

[valfri fot(er)]
```

### Exempel

```bash
📝 uppdatera dokumentation bidragsgivare

- Lägg till @jerembdn som en bidragsgivare
- Lägg till @younesbessa som en bidragsgivare

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

Mestadels räcker en enkel enradare:

```bash
📝 uppdatera dokumentation bidragsgivare
```

## Typer

Vi använder följande commit-typer:

| Typ | Beskrivning |
| --- | --- |
| `add` | Lägg till en ny funktion |
| `fix` | Fixa en bugg |
| `improve` | Förbättra något |
| `update` | Uppdatera något |
| `remove` | Ta bort något |
| `refactor` | Refaktorisera något |
| `rename` | Byt namn på något |
| `move` | Flytta en fil eller mapp |
| `upgrade` | Uppgradera beroenden |
| `downgrade` | Nedgradera beroenden |
| `initial` | Första commit av ett repository |
| `release` | Release / versionsetikett |

Den första commit av ett repository använder `initial`, och en versionsetikett använder
`release`:

```bash
🎉 första commit
🔖 release @onruntime/translations v0.3.0
```

## Beskrivning

`<typ>` är verbet av ämnet, och beskrivningen kompletterar det. Tillsammans gör de **en mening**:

```bash
# Bra
📝 uppdatera dokumentation bidragsgivare
```

Så öppna inte beskrivningen med ett andra verb. Typen är redan ett, och
ämnet kommer att stapla två meningar, vilket är vad en `fix:` prefix leder till. Droppa verbet och behåll det som det agerade på:

```bash
# Dåligt
💄 förbättra skala ner stenen på sitt kort
🐛 fixa stoppa foten från att rulla

# Bra
💄 förbättra storleken på stenen på sitt kort
🐛 fixa fotens rullning
```

Skriv det i **imperativ form** och **gemener**:

```bash
# Dåligt
📝 uppdaterad dokumentation bidragsgivare

# Dåligt
📝 Uppdatera dokumentation bidragsgivare
```

<Callout type="info" title="Ett Verb Som Är Ett Substantiv">
  Vissa ord är både, och det du menar är substantivet: `✨ add open graph image`
  är okej. När det läses som ett verb gör en artikel det till en substantivfras igen:
  `✨ add a show more button`.
</Callout>

## Ärendenummer

Länka commits till ärenden genom att lägga till ärendenumret:

```bash
📝 uppdatera dokumentation bidragsgivare (#123)
```

## Kropp

Använd kroppen för kontext och motivation:

```bash
📝 uppdatera dokumentation bidragsgivare

- Lägg till @jerembdn som en bidragsgivare
- Lägg till @younesbessa som en bidragsgivare

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

<Callout type="info" title="En Commit, Ett Syfte">
  Varje commit ska representera en enda logisk förändring. Blanda inte ihop orelaterade förändringar.
</Callout>
