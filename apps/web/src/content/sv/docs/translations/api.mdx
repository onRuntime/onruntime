## TranslationsProvider

Den provider-komponent som omsluter din applikation.

```tsx
import { TranslationsProvider } from "@onruntime/translations/react";

<TranslationsProvider
  locale="en"
  locales={{ en, fr }}
  fallbackLocale="en"
>
  {children}
</TranslationsProvider>
```

### Props

| Prop | Typ | Obligatorisk | Beskrivning |
|------|-----|--------------|-------------|
| `locale` | `string` | Ja | Nuvarande aktiva språkvariant |
| `locales` | `Record<string, object>` | Ja | Objekt som innehåller alla språkvariant-översättningar |
| `fallbackLocale` | `string` | Nej | Återgångsspråkvariant när nyckeln saknas |
| `children` | `ReactNode` | Ja | Barnkomponenter |

## useTranslation

Hook för att komma åt översättningar i klientkomponenter.

```tsx
const { t, locale, setLocale } = useTranslation("namespace");
```

### Parametrar

| Parameter | Typ | Obligatorisk | Beskrivning |
|-----------|-----|--------------|-------------|
| `namespace` | `string` | Ja | Översättningsnamnrymden som ska användas |

### Returer

| Egenskap | Typ | Beskrivning |
|----------|-----|-------------|
| `t` | `(key: string, vars?: object) => string` | Översättningsfunktion |
| `locale` | `string` | Nuvarande språkvariant |
| `setLocale` | `(locale: string) => void` | Funktion för att ändra språkvariant |

### Exempel

```tsx
const { t, locale, setLocale } = useTranslation("common");

// Grundläggande användning
t("greeting");  // "Hello"

// Med variabler
t("greeting_name", { name: "John" });  // "Hello, John!"

// Nedsatta nycklar
t("nav.home");  // "Home"

// Ändra språkvariant
setLocale("fr");
```

## getTranslation

Asynkron funktion för att komma åt översättningar i serverkomponenter (Next.js).

```tsx
const { t } = await getTranslation("namespace");
```

### Parametrar

| Parameter | Typ | Obligatorisk | Beskrivning |
|-----------|-----|--------------|-------------|
| `namespace` | `string` | Ja | Översättningsnamnrymden som ska användas |

### Returer

| Egenskap | Typ | Beskrivning |
|----------|-----|-------------|
| `t` | `(key: string, vars?: object) => string` | Översättningsfunktion |
| `locale` | `string` | Nuvarande språkvariant |

### Exempel

```tsx
// Serverkomponent
export default async function Page() {
  const { t } = await getTranslation("common");

  return <h1>{t("title")}</h1>;
}
```

## Link Component

Språkvariant-medveten Link-komponent för Next.js.

```tsx
import { Link } from "@onruntime/translations/next";

<Link href="/about">About</Link>
```

### Props

Alla props från Next.js `Link`-komponenten, plus:

| Prop | Typ | Standard | Beskrivning |
|------|-----|----------|-------------|
| `locale` | `string` | Nuvarande språkvariant | Åsidosätt länkspråkvarianten |

### Exempel

```tsx
// Använder nuvarande språkvariant
<Link href="/about">About</Link>

// Tvinga specifik språkvariant
<Link href="/about" locale="fr">À propos</Link>
```

## Translation Function (t)

`t`-funktionen används för att hämta översatta strängar.

### Signatur

```tsx
t(key: string, variables?: Record<string, string | number>): string
```

### Parametrar

| Parameter | Typ | Beskrivning |
|-----------|-----|-------------|
| `key` | `string` | Översättningsnyckel (stödjer punktnotation) |
| `variables` | `object` | Variabler för interpolering |

### Variabelinterpolering

```json
{
  "greeting": "Hello, {name}!",
  "items": "You have {count} items"
}
```

```tsx
t("greeting", { name: "Alice" });  // "Hello, Alice!"
t("items", { count: 5 });          // "You have 5 items"
```

### Pluralformer

Ett nummer som förändrar ordalydelsen går genom ett `plural`-argument istället för en
andra nyckel:

```json
{
  "battles": "{count, plural, one {# battle} other {# battles}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 battle"
t("battles", { count: 4 });  // "4 battles"
```

`#` står för antalet. Grenen väljs av `Intl.PluralRules` för
språkvarianten som läses, så varje språk skriver de grenar den behöver:

```json
{
  "battles": "{count, plural, one {# bitwa} few {# bitwy} many {# bitew} other {# bitwy}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 bitwa"
t("battles", { count: 3 });  // "3 bitwy"
t("battles", { count: 5 });  // "5 bitew"
```

Engelska och franska behöver två former, polska och ryska tre, arabiska sex, och
japanska bara en. En handskriven singular/plural-par kan inte uttrycka det: den
skriver 5-och-uppåt-formen på varje antal från två och uppåt.

En exakt matchning får företräde framför dess kategori, vilket är hur ett språk säger
"ingen" utan att påstå att det är nollkategorin:

```json
{
  "messages": "{count, plural, =0 {No messages} one {# message} other {# messages}}"
}
```

### Select

`select` matchar ett värde som angivet och faller tillbaka på `other`. Den har
grammatisk överensstämmelse när dina data känner till attributet:

```json
{
  "invited": "{gender, select, f {She} m {He} other {They}} joined the team"
}
```

```tsx
t("invited", { gender: "f" });  // "She joined the team"
t("invited", { gender: "x" });  // "They joined the team"
```

Attributet kan inte härledas från ordet självt, så passera det som en variabel.
För ett dynamiskt egennamn, föredra en formulering som inte behöver någon artikel alls.

Grener kan nestas, så en `select` kan innehålla en `plural`, och antingen kan hålla
vanliga variabler.

Endast `plural` och `select` stöds. Datum och nummer formateras bättre med `Intl` på
anropsstället, där du vet de alternativ du vill ha.

### Nedsatta Nycklar

```json
{
  "user": {
    "profile": {
      "title": "Profile"
    }
  }
}
```

```tsx
t("user.profile.title");  // "Profile"
```

## Typdefinitioner

### TranslationNamespaces

Utöka detta gränssnitt för typ-säker översättning:

```tsx
declare module "@onruntime/translations" {
  interface TranslationNamespaces {
    common: typeof import("./locales/en/common.json");
    auth: typeof import("./locales/en/auth.json");
  }
}
```

<Callout type="info" title="TypeScript Fördelar">
  Med ordentliga typdefinitioner får du autocompletion för översättningsnycklar och kompileringsfel för ogiltiga nycklar.
</Callout>
