## @onruntime/translations는 무엇인가요?

`@onruntime/translations`는 React와 Next.js 애플리케이션을 위해 설계된 경량형, 타입 안전한 국제화(i18n) 라이브러리입니다. 전체 TypeScript 지원을 제공하는 간단한 API로 번역을 관리할 수 있습니다.

<Callout type="info" title="주요 기능">
  - TypeScript를 통한 타입 안전한 번역
  - React 및 Next.js(App Router) 지원
  - 네임스페이스 기반 조직
  - 변수 삽입
  - ICU `plural` 및 `select`를 통한 복수형 및 문법적 일치
  - 경량이며 성능이 뛰어남
</Callout>

## 왜 사용해야 하나요?

### 타입 안전성

유효하지 않은 번역 키를 사용할 때 컴파일 오류를 가져옵니다:

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ 유효한 키
t("invalid_key");     // ❌ TypeScript 오류
```

### 간단한 API

모든 번역 요구를 위해 단 두 개의 훅이 필요합니다:

```typescript
// 클라이언트 구성 요소
const { t } = useTranslation("namespace");

// 서버 구성 요소 (Next.js)
const { t } = await getTranslation("namespace");
```

### 조직된 번역

네임스페이스로 번역을 체계적으로 정리하세요:

<Files>
  <Folder name="locales" defaultOpen>
    <Folder name="en" defaultOpen>

      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
    <Folder name="fr">
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
  </Folder>
</Files>

## 빠른 예제

```tsx
// locales/en/common.json
{
  "greeting": "Hello, {name}!"
}

// 컴포넌트
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
