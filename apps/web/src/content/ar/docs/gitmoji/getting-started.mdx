نحب أن يكون لدينا تاريخ مشروع نظيف. إن تقليد الالتزامات لدينا مستلهم من [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0) ولكن مُخصص بـ [gitmoji](https://gitmoji.dev) لجعله أكثر وضوحًا ومتعة.

## الهيكل

يجب أن تكون رسالة الالتزام منظمة كما يلي و **بالحروف الصغيرة**:

```
<gitmoji> <type> <description> [(#<issue number>)]

[optional body]

[optional footer(s)]
```

### مثال

```bash
📝 تحديث وثائق المساهمين

- إضافة @jerembdn كمساهم
- إضافة @younesbessa كمساهم

المؤلف المساعد: يونس بيسة <younes@onruntime.com>
```

معظم الوقت، سطر بسيط يكفي:

```bash
📝 تحديث وثائق المساهمين
```

## الأنواع

نستخدم الأنواع التالية من الالتزامات:

| النوع | الوصف |
| --- | --- |
| `add` | إضافة ميزة جديدة |
| `fix` | إصلاح خطأ |
| `improve` | تحسين شيء ما |
| `update` | تحديث شيء ما |
| `remove` | إزالة شيء ما |
| `refactor` | إعادة هيكلة شيء ما |
| `rename` | إعادة تسمية شيء ما |
| `move` | نقل ملف أو مجلد |
| `upgrade` | تحديث الاعتمادات |
| `downgrade` | إنقاص الاعتمادات |
| `initial` | الالتزام الأول لمستودع |
| `release` | إصدار / علامة الإصدار |

يستخدم أول التزام لمستودع `initial`، وتستخدم علامة الإصدار `release`:

```bash
🎉 الالتزام الأول
🔖 إصدار @onruntime/translations v0.3.0
```

## الوصف

الـ `<type>` هو الفعل للموضوع، والوصف يكمل ذلك. عندما تُقرأ معًا، تشكل **جملة واحدة**:

```bash
# جيد
📝 تحديث وثائق المساهمين
```

لذا لا تفتح الوصف بفعل ثانٍ. النوع هو بالفعل فعل، وينتهي الموضوع بتكديس جملتين، وهو ما يؤدي إليه بادئة `fix:`. اترك الفعل واحتفظ بما تم التصرف عليه:

```bash
# سيء
💄 تحسين تقليص حجم الجوهرة على بطاقتها
🐛 إصلاح توقف تداخل التذييل

# جيد
💄 تحسين حجم الجوهرة على بطاقتها
🐛 إصلاح تداخل التذييل
```

اكتبها في **حالة الأمر** و **الحروف الصغيرة**:

```bash
# سيء
📝 تم تحديث وثائق المساهمين

# سيء
📝 تحديث وثائق المساهمين
```

<Callout type="info" title="فعل هو اسم">
  بعض الكلمات هي كليهما، والكلمة التي تعنيها هي الاسم: `✨ إضافة صورة غلاف مفتوح`
  جيدة. عندما تُقرأ كفعل، فإن وجود أداة يجعلها عبارة اسمية مرة أخرى:
  `✨ إضافة زر "عرض المزيد"`.
</Callout>

## رقم القضية

رابط الالتزامات بالقضايا عن طريق إضافة رقم القضية:

```bash
📝 تحديث وثائق المساهمين (#123)
```

## الجسم

استخدم الجسم للسياق والدافع:

```bash
📝 تحديث وثائق المساهمين

- إضافة @jerembdn كمساهم
- إضافة @younesbessa كمساهم

المؤلف المساعد: يونس بيسة <younes@onruntime.com>
```

<Callout type="info" title="التزام واحد، غرض واحد">
  يجب أن يمثل كل التزام تغييرًا منطقيًا واحدًا. لا تخلط التغييرات غير ذات الصلة.
</Callout>
