نحن نحب أن تكون لدينا تاريخ مشروع نظيف. تقليد الالتزامات لدينا مستلهم من [الالتزامات التقليدية](https://www.conventionalcommits.org/en/v1.0.0) لكن مخصص مع [gitmoji](https://gitmoji.dev) لجعله أكثر بصرية وممتع.

## الهيكل

يجب أن تكون رسالة الالتزام مُهيكلة كما يلي و**بالحروف الصغيرة**:

```
<gitmoji> <type> <description> [(#<issue number>)]

[optional body]

[optional footer(s)]
```

### مثال

```bash
📝 تحديث مساهمات الوثائق

- إضافة @jerembdn كمساهم
- إضافة @younesbessa كمساهم

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

معظم الأوقات، سطر واحد بسيط يكفي:

```bash
📝 تحديث مساهمات الوثائق
```

## الأنواع

نستخدم أنواع الالتزامات التالية:

| النوع | الوصف |
| --- | --- |
| `add` | إضافة ميزة جديدة |
| `fix` | إصلاح خلل |
| `improve` | تحسين شيء ما |
| `update` | تحديث شيء ما |
| `remove` | إزالة شيء ما |
| `refactor` | إعادة هيكلة شيء ما |
| `rename` | إعادة تسمية شيء ما |
| `move` | نقل ملف أو مجلد |
| `upgrade` | ترقية التبعيات |
| `downgrade` | خفض التبعيات |
| `initial` | الالتزام الأول للمستودع |
| `release` | إصدار / علامة إصدار |

أول التزام لمستودع يستخدم `initial`، وعلامة الإصدار تستخدم
`release`:

```bash
🎉 الالتزام الأول
🔖 إصدار @onruntime/translations v0.3.0
```

## الوصف

اكتب أوصاف في **المزاج الأمر** و**بالحروف الصغيرة**:

```bash
# جيد
📝 تحديث مساهمات الوثائق

# سيء
📝 تحديثت مساهمات الوثائق

# سيء
📝 تحديث مساهمات الوثائق
```

## رقم القضية

اربط الالتزامات بالقضايا عن طريق إضافة رقم القضية:

```bash
📝 تحديث مساهمات الوثائق (#123)
```

## الجسم

استخدم الجسم للسياق والدافع:

```bash
📝 تحديث مساهمات الوثائق

- إضافة @jerembdn كمساهم
- إضافة @younesbessa كمساهم

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

<Callout type="info" title="التزام واحد، غرض واحد">
  يجب أن يمثل كل التزام تغييرًا منطقيًا واحدًا. لا تخلط التغييرات غير المتعلقة.
</Callout>
