ثبت الملحق gitmoji الخاص بنا لـ [Claude Code](https://claude.ai/code) لإنشاء التزامات تتبع الاتفاقية.

## تثبيت الملحق

أضف سوق onRuntime وثبت الملحق:

```bash
# أضف سوق onRuntime
/plugin marketplace add https://onruntime.com/plugins

# ثبت ملحق gitmoji
/plugin install gitmoji@onruntime
```

أو ثبته مباشرة من القائمة:

1. شغل `/plugin` في Claude Code
2. انتقل إلى علامة **Discover**
3. أضف السوق: `https://onruntime.com/plugins`
4. ابحث عن "gitmoji" وثبته

## الاستخدام

شغل الأمر `/commit` لإنشاء التزام:

```
/commit
```

```
/commit fix the login bug
```

Claude Code سيحلل تغييراتك وينشئ التزامًا يتبع اتفاقية gitmoji.

<Callout type="info" title="أمر الملحق">
  الأمر `/commit` يحصل تلقائيًا على حالة git الخاصة بك والاختلاف لإنشاء رسالة الالتزام المناسبة.
</Callout>

## بديل: CLAUDE.md

إذا كنت تفضل عدم تثبيت الملحق، أضف هذا إلى `CLAUDE.md` الخاص بمشروعك:

````markdown
## اتفاقية الالتزام

استخدم التزامات gitmoji التقليدية:

```
<gitmoji> <type> <description>
```

أنواع: add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

القواعد:
- اكتب بالأحرف الصغيرة
- النوع هو الفعل للموضوع، والوصف يكمله في جملة واحدة. احتفظ به أمرًا ("add" ليس "added")
- لا تبدأ الوصف بفعل ثانٍ: "fix the footer wrapping" وليس "fix stop the footer from wrapping"
- تعديل منطقي واحد لكل التزام
````
