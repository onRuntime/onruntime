## ما هو @onruntime/translations؟

`@onruntime/translations` هي مكتبة دولية خفيفة الوزن وآمنة من جهة النوع (i18n) مصممة لتطبيقات React و Next.js. توفر واجهة برمجية بسيطة لإدارة الترجمة مع دعم كامل لـ TypeScript.

<Callout type="info" title="الميزات الأساسية">
  - ترجمات آمنة من جهة النوع مع TypeScript
  - دعم لـ React و Next.js (موجه التطبيق)
  - تنظيم قائم على المساحات الاسمية
  - إدراج متغيرات
  - الجمع والموافقة النحوية من خلال ICU `plural` و `select`
  - خفيفة الوزن وعالية الأداء
</Callout>

## لماذا ينبغي استخدامه؟

### الأمان من جهة النوع

احصل على أخطاء في وقت التجميع عند استخدام مفاتيح ترجمة غير صحيحة:

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ مفتاح صحيح
t("invalid_key");     // ❌ خطأ في TypeScript
```

### واجهة برمجية بسيطة

فقط اثنان من الهوكات لجميع احتياجاتك في الترجمة:

```typescript
// مكونات العميل
const { t } = useTranslation("namespace");

// مكونات الخادم (Next.js)
const { t } = await getTranslation("namespace");
```

### ترجمات منظمة

احتفظ بترجماتك منظمة مع المساحات الاسمية:

<Files>
  <Folder name="locales" defaultOpen>
    <Folder name="en" defaultOpen>
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
    <Folder name="fr">
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
  </Folder>
</Files>

## مثال سريع

```tsx
// locales/en/common.json
{
  "greeting": "Hello, {name}!"
}

// المكون
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
