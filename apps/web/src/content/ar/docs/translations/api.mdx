## TranslationsProvider

مكون المزود الذي يلف تطبيقك.

```tsx
import { TranslationsProvider } from "@onruntime/translations/react";

<TranslationsProvider
  locale="ar"
  locales={{ en, fr }}
  fallbackLocale="en"
>
  {children}
</TranslationsProvider>
```

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `locale` | `string` | نعم | اللغة النشطة الحالية |
| `locales` | `Record<string, object>` | نعم | كائن يحتوي على جميع ترجمات اللغات |
| `fallbackLocale` | `string` | لا | اللغة الاحتياطية عند فقدان المفتاح |
| `children` | `ReactNode` | نعم | مكونات الأطفال |

## useTranslation

خطاف للوصول إلى الترجمات في مكونات العميل.

```tsx
const { t, locale, setLocale } = useTranslation("namespace");
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `namespace` | `string` | نعم | مساحة اسم الترجمة للاستخدام |

### Returns

| Property | Type | Description |
|----------|------|-------------|
| `t` | `(key: string, vars?: object) => string` | دالة الترجمة |
| `locale` | `string` | اللغة الحالية |
| `setLocale` | `(locale: string) => void` | دالة لتغيير اللغة |

### Example

```tsx
const { t, locale, setLocale } = useTranslation("common");

// استخدام أساسي
t("greeting");  // "مرحبا"

// مع متغيرات
t("greeting_name", { name: "جون" });  // "مرحبا، جون!"

// مفاتيح متداخلة
t("nav.home");  // "الرئيسية"

// تغيير اللغة
setLocale("fr");
```

## getTranslation

وظيفة غير متزامنة للوصول إلى الترجمات في مكونات الخادم (Next.js).

```tsx
const { t } = await getTranslation("namespace");
```

### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `namespace` | `string` | نعم | مساحة اسم الترجمة للاستخدام |

### Returns

| Property | Type | Description |
|----------|------|-------------|
| `t` | `(key: string, vars?: object) => string` | دالة الترجمة |
| `locale` | `string` | اللغة الحالية |

### Example

```tsx
// مكون الخادم
export default async function Page() {
  const { t } = await getTranslation("common");

  return <h1>{t("title")}</h1>;
}
```

## Link Component

مكون Link الواعي للغة لـ Next.js.

```tsx
import { Link } from "@onruntime/translations/next";

<Link href="/about">حول</Link>
```

### Props

جميع الخصائص من مكون `Link` في Next.js، بالإضافة إلى:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `locale` | `string` | اللغة الحالية | تجاوز لغة الرابط |

### Example

```tsx
// يستخدم اللغة الحالية
<Link href="/about">حول</Link>

// قوة لغة معينة
<Link href="/about" locale="fr">À propos</Link>
```

## Translation Function (t)

تستخدم دالة `t` لاسترجاع السلاسل المترجمة.

### Signature

```tsx
t(key: string, variables?: Record<string, string | number>): string
```

### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `key` | `string` | مفتاح الترجمة (يدعم التنسيق النقطي) |
| `variables` | `object` | متغيرات للإدماج |

### Variable Interpolation

```json
{
  "greeting": "مرحبا، {name}!",
  "items": "لديك {count} عناصر"
}
```

```tsx
t("greeting", { name: "أليس" });  // "مرحبا، أليس!"
t("items", { count: 5 });          // "لديك 5 عناصر"
```

### Plurals

رقم يغير صياغة الكلمات يمر عبر حجة `plural` بدلاً من مفتاح ثانٍ:

```json
{
  "battles": "{count, plural, one {# معركة} other {# معارك}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 معركة"
t("battles", { count: 4 });  // "4 معارك"
```

`#` يرمز إلى العدد. يتم اختيار الفرع بواسطة `Intl.PluralRules` في اللغة التي تتم قراءتها، لذلك كل لغة تكتب الفروع التي تحتاجها:

```json
{
  "battles": "{count, plural, one {# bitwa} few {# bitwy} many {# bitew} other {# bitwy}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 bitwa"
t("battles", { count: 3 });  // "3 bitwy"
t("battles", { count: 5 });  // "5 bitew"
```

الإنجليزية والفرنسية تحتاج إلى شكلين، البولندية والروسية ثلاثة، العربية ستة، واليابانية واحدة فقط. لا يمكن لزوج المفرد/الجمع المكتوب يدويًا التعبير عن ذلك: يكتب الشكل 5 وما فوق على كل عدد من اثنين فصاعدًا.

تأخذ المطابقة الدقيقة الأولوية على فئتها، وهذا هو كيف تقول لغة "لا شيء" دون الادعاء أنها فئة صفر:

```json
{
  "messages": "{count, plural, =0 {لا رسائل} one {# رسالة} other {# رسائل}}"
}
```

### Select

`select` يطابق قيمة مكتوبة ويعود إلى `other`. يحمل اتفاقًا نحويًا عندما تعرف بياناتك السمة:

```json
{
  "invited": "{gender, select, f {هي} m {هو} other {هم}} انضم إلى الفريق"
}
```

```tsx
t("invited", { gender: "f" });  // "هي انضمت إلى الفريق"
t("invited", { gender: "x" });  // "هم انضموا إلى الفريق"
```

لا يمكن اشتقاق السمة من الكلمة نفسها، لذا تمررها كمتغير. بالنسبة لاسم علم ديناميكي، يفضل عبارة لا تحتاج إلى أداة على الإطلاق.

تتداخل الفروع، لذا قد يحمل `select` `plural`، وأي منهما قد يحمل متغيرات عادية.

فقط `plural` و `select` مدعومة. من الأفضل تنسيق التواريخ والأرقام مع `Intl` في موقع الاتصال، حيث تعرف الخيارات التي تريدها.

### Nested Keys

```json
{
  "user": {
    "profile": {
      "title": "الملف الشخصي"
    }
  }
}
```

```tsx
t("user.profile.title");  // "الملف الشخصي"
```

## Type Definitions

### TranslationNamespaces

قم بتمديد هذه الواجهة من أجل ترجمات آمنة من حيث النوع:

```tsx
declare module "@onruntime/translations" {
  interface TranslationNamespaces {
    common: typeof import("./locales/ar/common.json");
    auth: typeof import("./locales/ar/auth.json");
  }
}
```

<Callout type="info" title="فوائد TypeScript">
  مع تعريفات النوع الصحيحة، ستحصل على الإكمال التلقائي لمفاتيح الترجمة وأخطاء في وقت الترجمة للمفاتيح غير الصالحة.
</Callout>
