Nos gusta tener un historial de proyecto limpio. Nuestra convención de commits está inspirada en [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0) pero personalizada con [gitmoji](https://gitmoji.dev) para hacerlo más visual y divertido.

## Estructura

El mensaje del commit debe estar estructurado de la siguiente manera y **en minúsculas**:

```
<gitmoji> <tipo> <descripción> [(#<número de issue>)]

[cuerpo opcional]

[pie opcional(s)]
```

### Ejemplo

```bash
📝 actualizar contribuyentes de la documentación

- Agregar @jerembdn como contribuyente
- Agregar @younesbessa como contribuyente

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

La mayoría de las veces, una simple línea es suficiente:

```bash
📝 actualizar contribuyentes de la documentación
```

## Tipos

Usamos los siguientes tipos de commit:

| Tipo | Descripción |
| --- | --- |
| `add` | Agregar una nueva característica |
| `fix` | Arreglar un bug |
| `improve` | Mejorar algo |
| `update` | Actualizar algo |
| `remove` | Eliminar algo |
| `refactor` | Refactorizar algo |
| `rename` | Renombrar algo |
| `move` | Mover un archivo o carpeta |
| `upgrade` | Actualizar dependencias |
| `downgrade` | Degradar dependencias |
| `initial` | Primer commit de un repositorio |
| `release` | Lanzar / etiqueta de versión |

El primer commit de un repositorio usa `initial`, y una etiqueta de versión usa
`release`:

```bash
🎉 primer commit
🔖 lanzamiento @onruntime/translations v0.3.0
```

## Descripción

Escribe descripciones en **modo imperativo** y **minúsculas**:

```bash
# Bueno
📝 actualizar contribuyentes de la documentación

# Malo
📝 actualizados contribuyentes de la documentación

# Malo
📝 Actualizar contribuyentes de la documentación
```

## Número de Issue

Vincula commits a issues agregando el número de issue:

```bash
📝 actualizar contribuyentes de la documentación (#123)
```

## Cuerpo

Usa el cuerpo para contexto y motivación:

```bash
📝 actualizar contribuyentes de la documentación

- Agregar @jerembdn como contribuyente
- Agregar @younesbessa como contribuyente

Co-authored-by: Younes Bessa <younes@onruntime.com>
```

<Callout type="info" title="Un Commit, Un Propósito">
  Cada commit debería representar un cambio lógico único. No mezcles cambios no relacionados.
</Callout>
