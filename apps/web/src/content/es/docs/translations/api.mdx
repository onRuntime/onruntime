## TranslationsProvider

El componente proveedor que envuelve tu aplicación.

```tsx
import { TranslationsProvider } from "@onruntime/translations/react";

<TranslationsProvider
  locale="en"
  locales={{ en, fr }}
  fallbackLocale="en"
>
  {children}
</TranslationsProvider>
```

### Props

| Prop | Tipo | Requerido | Descripción |
|------|------|-----------|-------------|
| `locale` | `string` | Sí | Locale activa actual |
| `locales` | `Record<string, object>` | Sí | Objeto que contiene todas las traducciones de locales |
| `fallbackLocale` | `string` | No | Locale de respaldo cuando falta una clave |
| `children` | `ReactNode` | Sí | Componentes hijos |

## useTranslation

Hook para acceder a traducciones en componentes del cliente.

```tsx
const { t, locale, setLocale } = useTranslation("namespace");
```

### Parámetros

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| `namespace` | `string` | Sí | Espacio de nombres de traducción a utilizar |

### Retornos

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `t` | `(key: string, vars?: object) => string` | Función de traducción |
| `locale` | `string` | Locale actual |
| `setLocale` | `(locale: string) => void` | Función para cambiar el locale |

### Ejemplo

```tsx
const { t, locale, setLocale } = useTranslation("common");

// Uso básico
t("greeting");  // "Hello"

// Con variables
t("greeting_name", { name: "John" });  // "Hello, John!"

// Claves anidadas
t("nav.home");  // "Home"

// Cambiar locale
setLocale("fr");
```

## getTranslation

Función asíncrona para acceder a traducciones en componentes del servidor (Next.js).

```tsx
const { t } = await getTranslation("namespace");
```

### Parámetros

| Parámetro | Tipo | Requerido | Descripción |
|-----------|------|-----------|-------------|
| `namespace` | `string` | Sí | Espacio de nombres de traducción a utilizar |

### Retornos

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `t` | `(key: string, vars?: object) => string` | Función de traducción |
| `locale` | `string` | Locale actual |

### Ejemplo

```tsx
// Componente del servidor
export default async function Page() {
  const { t } = await getTranslation("common");

  return <h1>{t("title")}</h1>;
}
```

## Link Component

Componente Link consciente del locale para Next.js.

```tsx
import { Link } from "@onruntime/translations/next";

<Link href="/about">About</Link>
```

### Props

Todos los props del componente `Link` de Next.js, además de:

| Prop | Tipo | Predeterminado | Descripción |
|------|------|----------------|-------------|
| `locale` | `string` | Locale actual | Sobrescribir el locale del enlace |

### Ejemplo

```tsx
// Usa el locale actual
<Link href="/about">About</Link>

// Forzar un locale específico
<Link href="/about" locale="fr">À propos</Link>
```

## Translation Function (t)

La función `t` se utiliza para recuperar cadenas traducidas.

### Firma

```tsx
t(key: string, variables?: Record<string, string | number>): string
```

### Parámetros

| Parámetro | Tipo | Descripción |
|-----------|------|-------------|
| `key` | `string` | Clave de traducción (soporta notación por puntos) |
| `variables` | `object` | Variables para interpolar |

### Interpolación de Variables

```json
{
  "greeting": "Hello, {name}!",
  "items": "You have {count} items"
}
```

```tsx
t("greeting", { name: "Alice" });  // "Hello, Alice!"
t("items", { count: 5 });          // "You have 5 items"
```

### Plurales

Un número que cambia la redacción pasa por un argumento `plural` en lugar de una segunda clave:

```json
{
  "battles": "{count, plural, one {# battle} other {# battles}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 battle"
t("battles", { count: 4 });  // "4 battles"
```

`#` representa el conteo. La rama se elige por `Intl.PluralRules` en el locale que se está leyendo, así que cada idioma escribe las ramas que necesita:

```json
{
  "battles": "{count, plural, one {# bitwa} few {# bitwy} many {# bitew} other {# bitwy}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 bitwa"
t("battles", { count: 3 });  // "3 bitwy"
t("battles", { count: 5 });  // "5 bitew"
```

El inglés y el francés necesitan dos formas, el polaco y el ruso tres, el árabe seis, y el japonés solo una. Un par singular/plural escrito a mano no puede expresar eso: escribe la forma de 5 y superiores en cada conteo de dos hacia arriba.

Una coincidencia exacta tiene prioridad sobre su categoría, que es como un idioma dice "ninguno" sin reclamar que es la categoría cero:

```json
{
  "messages": "{count, plural, =0 {No messages} one {# message} other {# messages}}"
}
```

### Select

`select` coincide con un valor tal como está escrito y vuelve a `other`. Tiene concordancia gramatical cuando tus datos conocen el atributo:

```json
{
  "invited": "{gender, select, f {She} m {He} other {They}} joined the team"
}
```

```tsx
t("invited", { gender: "f" });  // "She joined the team"
t("invited", { gender: "x" });  // "They joined the team"
```

El atributo no puede derivarse de la palabra misma, así que pásalo como una variable. Para un nombre propio dinámico, prefiere una frase que no necesite artículo en absoluto.

Las ramas se anidan, así que un `select` puede contener un `plural`, y cualquiera de ellos puede contener variables simples.

Solo se admiten `plural` y `select`. Las fechas y los números son mejor formateados con `Intl` en el sitio de llamada, donde conoces las opciones que deseas.

### Claves Anidadas

```json
{
  "user": {
    "profile": {
      "title": "Profile"
    }
  }
}
```

```tsx
t("user.profile.title");  // "Profile"
```

## Definiciones de Tipos

### TranslationNamespaces

Extiende esta interfaz para traducciones seguras en tipo:

```tsx
declare module "@onruntime/translations" {
  interface TranslationNamespaces {
    common: typeof import("./locales/en/common.json");
    auth: typeof import("./locales/en/auth.json");
  }
}
```

<Callout type="info" title="Beneficios de TypeScript">
  Con definiciones de tipos adecuadas, obtendrás autocompletado para claves de traducción y errores en tiempo de compilación para claves inválidas.
</Callout>
