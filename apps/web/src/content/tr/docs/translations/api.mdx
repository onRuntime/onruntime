## TranslationsProvider

Uygulamanızı saran sağlayıcı bileşeni.

```tsx
import { TranslationsProvider } from "@onruntime/translations/react";

<TranslationsProvider
  locale="tr"
  locales={{ en, fr }}
  fallbackLocale="en"
>
  {children}
</TranslationsProvider>
```

### Props

| Prop | Tip | Gerekli | Açıklama |
|------|------|----------|-------------|
| `locale` | `string` | Evet | Geçerli aktif dil |
| `locales` | `Record<string, object>` | Evet | Tüm dil çevirilerini içeren nesne |
| `fallbackLocale` | `string` | Hayır | Anahtar eksik olduğunda yedek dil |
| `children` | `ReactNode` | Evet | Çocuk bileşenler |

## useTranslation

İstemci bileşenlerinde çevirilere erişmek için hook.

```tsx
const { t, locale, setLocale } = useTranslation("namespace");
```

### Parametreler

| Parametre | Tip | Gerekli | Açıklama |
|-----------|------|----------|-------------|
| `namespace` | `string` | Evet | Kullanılacak çeviri ad alanı |

### Dönüşler

| Özellik | Tip | Açıklama |
|----------|------|-------------|
| `t` | `(key: string, vars?: object) => string` | Çeviri fonksiyonu |
| `locale` | `string` | Geçerli dil |
| `setLocale` | `(locale: string) => void` | Dili değiştirmek için fonksiyon |

### Örnek

```tsx
const { t, locale, setLocale } = useTranslation("common");

// Temel kullanım
t("greeting");  // "Merhaba"

// Değişkenlerle
t("greeting_name", { name: "John" });  // "Merhaba, John!"

// İç içe anahtarlar
t("nav.home");  // "Ana Sayfa"

// Dili değiştirme
setLocale("fr");
```

## getTranslation

Sunucu bileşenlerinde (Next.js) çevirilere erişmek için asenkron fonksiyon.

```tsx
const { t } = await getTranslation("namespace");
```

### Parametreler

| Parametre | Tip | Gerekli | Açıklama |
|-----------|------|----------|-------------|
| `namespace` | `string` | Evet | Kullanılacak çeviri ad alanı |

### Dönüşler

| Özellik | Tip | Açıklama |
|----------|------|-------------|
| `t` | `(key: string, vars?: object) => string` | Çeviri fonksiyonu |
| `locale` | `string` | Geçerli dil |

### Örnek

```tsx
// Sunucu Bileşeni
export default async function Page() {
  const { t } = await getTranslation("common");

  return <h1>{t("title")}</h1>;
}
```

## Link Bileşeni

Next.js için dil farkındalığı olan Link bileşeni.

```tsx
import { Link } from "@onruntime/translations/next";

<Link href="/about">Hakkında</Link>
```

### Props

Next.js `Link` bileşeninden tüm props'lar, ayrıca:

| Prop | Tip | Varsayılan | Açıklama |
|------|------|---------|-------------|
| `locale` | `string` | Geçerli dil | Bağlantı dilini geçersiz kıl |

### Örnek

```tsx
// Geçerli dili kullanır
<Link href="/about">Hakkında</Link>

// Belirli bir dili zorla
<Link href="/about" locale="fr">À propos</Link>
```

## Çeviri Fonksiyonu (t)

`t` fonksiyonu, çevrilmiş dizeleri almak için kullanılır.

### İmza

```tsx
t(key: string, variables?: Record<string, string | number>): string
```

### Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `key` | `string` | Çeviri anahtarı (nokta notasyonu desteklenir) |
| `variables` | `object` | Değişkenleri yerleştirmek için |

### Değişken Yerleştirme

```json
{
  "greeting": "Merhaba, {name}!",
  "items": "Elinizde {count} öğe var"
}
```

```tsx
t("greeting", { name: "Alice" });  // "Merhaba, Alice!"
t("items", { count: 5 });          // "Elinizde 5 öğe var"
```

### Çoğullar

Sözcüğün değiştiği bir sayı `plural` argümanından geçiyor, ikinci anahtar yerine:

```json
{
  "battles": "{count, plural, one {# savaş} other {# savaşlar}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 savaş"
t("battles", { count: 4 });  // "4 savaşlar"
```

`#` sayıyı temsil eder. Dallanma, okunan dildeki `Intl.PluralRules` tarafından seçilir, böylece her dil ihtiyaç duyduğu dalları yazar:

```json
{
  "battles": "{count, plural, one {# bitwa} few {# bitwy} many {# bitew} other {# bitwy}}"
}
```

```tsx
t("battles", { count: 1 });  // "1 bitwa"
t("battles", { count: 3 });  // "3 bitwy"
t("battles", { count: 5 });  // "5 bitew"
```

İngilizce ve Fransızca iki form, Lehçe ve Rusça üç, Arapça altı, ve Japonca sadece bir form istiyor. El yazısı tekil/çoğul çifti bunu ifade edemez: iki ve üzerindeki her sayıda 5 ve üzeri formunu yazar.

Kesin bir eşleşme, kategorisini önceliklendirir. Bu da bir dilin "hiç" dediğinde bunu sıfır kategorisi olduğunu iddia etmeden nasıl söylediğidir:

```json
{
  "messages": "{count, plural, =0 {Hiç mesaj yok} one {# mesaj} other {# mesajlar}}"
}
```

### Seç

`select`, bir değeri yazıldığı gibi eşleştirir ve `other`'a geri döner. Veriniz özellikleri bildiğinde dil bilgisel uyumu taşır:

```json
{
  "invited": "{gender, select, f {O} m {O} other {Onlar}} takıma katıldı"
}
```

```tsx
t("invited", { gender: "f" });  // "O takıma katıldı"
t("invited", { gender: "x" });  // "Onlar takıma katıldı"
```

Özellik kelimeden türetilemez, bu yüzden bir değişken olarak geçirin. Dinamik bir özel isim için, hiç makale gerektirmeyen bir ifadeyi tercih edin.

Dallar iç içe geçebilir, yani bir `select` bir `plural` tutabilir ve biri basit değişkenler tutabilir.

Yalnızca `plural` ve `select` desteklenmektedir. Tarihler ve sayılar, istediğiniz seçenekleri bildiğiniz yerlerde `Intl` ile daha iyi biçimlendirilir.

### İç İçe Anahtarlar

```json
{
  "user": {
    "profile": {
      "title": "Profil"
    }
  }
}
```

```tsx
t("user.profile.title");  // "Profil"
```

## Tip Tanımları

### TranslationNamespaces

Tip güvenli çeviriler için bu arayüzü genişletin:

```tsx
declare module "@onruntime/translations" {
  interface TranslationNamespaces {
    common: typeof import("./locales/en/common.json");
    auth: typeof import("./locales/en/auth.json");
  }
}
```

<Callout type="info" title="TypeScript Faydaları">
  Uygun tip tanımları ile çeviri anahtarları için otomatik tamamlama ve geçersiz anahtarlar için derleme zamanı hataları alacaksınız.
</Callout>
