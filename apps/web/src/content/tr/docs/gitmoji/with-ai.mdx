Install our gitmoji eklentisini [Claude Code](https://claude.ai/code) için, konvensiyona uygun commit'ler oluşturmak üzere.

## Eklentiyi Yükle

onRuntime marketplace'ini ekleyin ve eklentiyi yükleyin:

```bash
# onRuntime marketplace'ini ekle
/plugin marketplace add https://onruntime.com/plugins

# gitmoji eklentisini yükle
/plugin install gitmoji@onruntime
```

Ya da menüden doğrudan yükleyin:

1. Claude Code'da `/plugin` çalıştırın
2. **Discover** sekmesine gidin
3. Marketplace ekleyin: `https://onruntime.com/plugins`
4. "gitmoji" için arama yapın ve yükleyin

## Kullanım

Bir commit oluşturmak için `/commit` komutunu çalıştırın:

```
/commit
```

```
/commit fix the login bug
```

Claude Code, değişikliklerinizi analiz eder ve gitmoji konvensiyonuna uygun bir commit oluşturur.

<Callout type="info" title="Eklenti Komutu">
  `/commit` komutu otomatik olarak git durumunuzu ve diff'inizi alarak uygun commit mesajını oluşturur.
</Callout>

## Alternatif: CLAUDE.md

Eklentiyi yüklemek istemiyorsanız, projenizin `CLAUDE.md` dosyasına bunu ekleyin:

````markdown
## Commit Konvansiyonu

gitmoji geleneksel commit'leri kullanın:

```
<gitmoji> <type> <description>
```

Türler: add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

Kurallar:
- Küçük harfle yazın
- Tür, konunun fiilidir ve açıklama onu bir cümle haline getirir. Emir kipinde tutun ("add" değil "added")
- Açıklamayı ikinci bir fiille başlatmayın: "fix the footer wrapping", "fix stop the footer from wrapping" değil
- Her commit için bir mantıklı değişiklik
````
