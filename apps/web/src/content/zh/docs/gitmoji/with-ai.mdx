安装我们的 gitmoji 插件用于 [Claude Code](https://claude.ai/code)，以生成符合规范的提交。

## 安装插件

添加 onRuntime 市场并安装插件：

```bash
# 添加 onRuntime 市场
/plugin marketplace add https://onruntime.com/plugins

# 安装 gitmoji 插件
/plugin install gitmoji@onruntime
```

或者直接从菜单安装：

1. 在 Claude Code 中运行 `/plugin`
2. 转到 **Discover** 标签
3. 添加市场： `https://onruntime.com/plugins`
4. 搜索 "gitmoji" 并安装

## 使用方法

运行 `/commit` 命令以创建提交：

```
/commit
```

```
/commit fix the login bug
```

Claude Code 将分析你的更改并生成符合 gitmoji 规范的提交。

<Callout type="info" title="插件命令">
  `/commit` 命令会自动获取你的 git 状态和差异，以生成适当的提交信息。
</Callout>

## 备选方案：CLAUDE.md

如果你不想安装插件，可以将以下内容添加到你项目的 `CLAUDE.md`：

````markdown
## 提交规范

使用 gitmoji 传统提交：

```
<gitmoji> <type> <description>
```

类型：add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

规则：
- 使用小写字母
- 类型是主语的动词，描述补充成一个完整的句子。保持命令式（用 "add" 而不是 "added"）
- 描述开头永远不要用第二个动词：“修复页脚换行”，而不是“修复停止页脚换行”
- 每个提交要有一个逻辑变更
````
