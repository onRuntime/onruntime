## Cos'è @onruntime/translations?

`@onruntime/translations` è una libreria leggera e type-safe per l'internazionalizzazione (i18n) progettata per applicazioni React e Next.js. Fornisce un'API semplice per gestire le traduzioni con supporto completo per TypeScript.

<Callout type="info" title="Caratteristiche principali">
  - Traduzioni type-safe con TypeScript
  - Supporto per React e Next.js (App Router)
  - Organizzazione basata su namespace
  - Interpolazione di variabili
  - Plurali e accordo grammaticale tramite ICU `plural` e `select`
  - Leggera e performante
</Callout>

## Perché usarlo?

### Sicurezza dei Tipi

Ricevi errori di compilazione quando usi chiavi di traduzione non valide:

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ Chiave valida
t("invalid_key");     // ❌ Errore TypeScript
```

### API Semplice

Solo due hook per tutte le tue esigenze di traduzione:

```typescript
// Client Components
const { t } = useTranslation("namespace");

// Server Components (Next.js)
const { t } = await getTranslation("namespace");
```

### Traduzioni Organizzate

Tieni le tue traduzioni organizzate con i namespace:

## Esempio Veloce

```tsx
// locales/en/common.json
{
  "greeting": "Ciao, {name}!"
}

// Component
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
