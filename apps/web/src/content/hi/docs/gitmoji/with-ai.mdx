Install our gitmoji plugin for [Claude Code](https://claude.ai/code) to generate commits following the convention.

## प्लगइन इंस्टॉल करें

onRuntime मार्केटप्लेस जोड़ें और प्लगइन इंस्टॉल करें:

```bash
# onRuntime मार्केटप्लेस जोड़ें
/plugin marketplace add https://onruntime.com/plugins

# gitmoji प्लगइन इंस्टॉल करें
/plugin install gitmoji@onruntime
```

या मेनू से सीधे इंस्टॉल करें:

1. Claude Code में `/plugin` चलाएं
2. **Discover** टैब पर जाएं
3. मार्केटप्लेस जोड़ें: `https://onruntime.com/plugins`
4. "gitmoji" के लिए खोजें और इंस्टॉल करें

## उपयोग

कमिट बनाने के लिए `/commit` कमांड चलाएं:

```
/commit
```

```
/commit fix the login bug
```

Claude Code आपके बदलावों का विश्लेषण करेगा और gitmoji कंवेंशन के अनुसार एक कमिट बनाएगा।

<Callout type="info" title="प्लगइन कमांड">
  `/commit` कमांड स्वचालित रूप से आपके git स्थिति और डिफ़ को लाकर उपयुक्त कमिट संदेश बनाने के लिए जनरेट करता है।
</Callout>

## वैकल्पिक: CLAUDE.md

यदि आप प्लगइन इंस्टॉल नहीं करना चाहते हैं, तो इसे अपने प्रोजेक्ट के `CLAUDE.md` में जोड़ें:

````markdown
## कमिट कंवेंशन

gitmoji सामान्य कमिट्स का उपयोग करें:

```
<gitmoji> <type> <description>
```

प्रकार: add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

नियम:
- छोटे अक्षरों में लिखें
- प्रकार विषय का क्रिया है, और विवरण इसे एक वाक्य में पूरा करता है। इसे अधिनियमात्मक रखें ("add" न कि "added")
- विवरण को एक दूसरे क्रिया से मत खोलें: "fix the footer wrapping", न कि "fix stop the footer from wrapping"
- प्रत्येक कमिट में एक तार्किक बदलाव
````
