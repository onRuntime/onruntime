## @onruntime/translations क्या है?

`@onruntime/translations` एक हल्का, टाइप-सुरक्षित अंतर्राष्ट्रीयकरण (i18n) लाइब्रेरी है जिसे React और Next.js एप्लिकेशन के लिए डिज़ाइन किया गया है। यह पूर्ण TypeScript समर्थन के साथ अनुवादों का प्रबंधन करने के लिए एक सरल API प्रदान करता है।

<Callout type="info" title="मुख्य विशेषताएँ">
  - TypeScript के साथ टाइप-सुरक्षित अनुवाद
  - React और Next.js (ऐप राउटर) के लिए समर्थन
  - नेमस्पेस-आधारित संगठन
  - वेरिएबल इंटरपोलेशन
  - ICU `plural` और `select` के माध्यम से बहुवचन और व्याकरणिक सहमति
  - हल्का और प्रदर्शन में अच्छा
</Callout>

## इसका उपयोग क्यों करें?

### टाइप सुरक्षा

अमान्य अनुवाद कुंजी का उपयोग करने पर संकलन-समय की त्रुटियाँ प्राप्त करें:

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ मान्य कुंजी
t("invalid_key");     // ❌ TypeScript त्रुटि
```

### सरल API

आपकी सभी अनुवाद आवश्यकताओं के लिए केवल दो हुक:

```typescript
// क्लाइंट कंपोनेंट्स
const { t } = useTranslation("namespace");

// सर्वर कंपोनेंट्स (Next.js)
const { t } = await getTranslation("namespace");
```

### व्यवस्थित अनुवाद

नेमस्पेस के साथ अपने अनुवादों को व्यवस्थित रखें:

<Files>
  <Folder name="locales" defaultOpen>
    <Folder name="en" defaultOpen>
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
    <Folder name="fr">
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
  </Folder>
</Files>

## त्वरित उदाहरण

```tsx
// locales/en/common.json
{
  "greeting": "Hello, {name}!"
}

// कंपोनेंट
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
