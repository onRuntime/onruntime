## @onruntime/translations とは何ですか？

`@onruntime/translations`は、ReactとNext.jsアプリケーションのために設計された軽量で型安全な国際化（i18n）ライブラリです。完全なTypeScriptサポートを提供するシンプルなAPIで翻訳を管理します。

<Callout type="info" title="主な機能">
  - TypeScriptによる型安全な翻訳
  - ReactとNext.js（App Router）をサポート
  - 名前空間ベースの整理
  - 変数の補間
  - ICUの`plural`および`select`による複数形と文法的合意
  - 軽量でパフォーマンスが高い
</Callout>

## なぜ使うの？

### 型安全性

無効な翻訳キーを使用するとコンパイル時エラーが発生します：

```typescript
const { t } = useTranslation("common");

t("greeting");        // ✅ 有効なキー
t("invalid_key");     // ❌ TypeScriptエラー
```

### シンプルなAPI

翻訳ニーズに対してたった2つのフックだけ：

```typescript
// クライアントコンポーネント
const { t } = useTranslation("namespace");

// サーバーコンポーネント（Next.js）
const { t } = await getTranslation("namespace");
```

### 整理された翻訳

名前空間で翻訳を整理しましょう：

<Files>
  <Folder name="locales" defaultOpen>
    <Folder name="en" defaultOpen>
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
    <Folder name="fr">
      <File name="common.json" />
      <File name="auth.json" />
      <File name="dashboard.json" />
    </Folder>
  </Folder>
</Files>

## クイック例

```tsx
// locales/en/common.json
{
  "greeting": "こんにちは、{name}!"
}

// コンポーネント
import { useTranslation } from "@onruntime/translations/react";

function Welcome({ name }) {
  const { t } = useTranslation("common");

  return <h1>{t("greeting", { name })}</h1>;
}
```
