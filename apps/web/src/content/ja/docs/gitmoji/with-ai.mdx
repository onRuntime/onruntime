gitmoji プラグインを [Claude Code](https://claude.ai/code) にインストールして、規約に従ったコミットを生成しよう。

## プラグインのインストール

onRuntime マーケットプレイスを追加して、プラグインをインストールする：

```bash
# onRuntime マーケットプレイスを追加
/plugin marketplace add https://onruntime.com/plugins

# gitmoji プラグインをインストール
/plugin install gitmoji@onruntime
```

または、メニューから直接インストールする：

1. Claude Code で `/plugin` を実行
2. **Discover** タブに移動
3. マーケットプレイスを追加: `https://onruntime.com/plugins`
4. "gitmoji" を検索してインストール

## 使い方

`/commit` コマンドを実行して、コミットを作成する：

```
/commit
```

```
/commit fix the login bug
```

Claude Code はあなたの変更を分析して、gitmoji 規約に従ったコミットを作成するよ。

<Callout type="info" title="プラグインコマンド">
  `/commit` コマンドは自動的にあなたの git ステータスと diff を取得して、適切なコミットメッセージを生成するよ。
</Callout>

## 代替案: CLAUDE.md

プラグインをインストールしたくない場合は、あなたのプロジェクトの `CLAUDE.md` にこれを追加してね：

````markdown
## コミット規約

gitmoji の従来のコミットを使おう：

```
<gitmoji> <type> <description>
```

タイプ: add, fix, improve, update, remove, refactor, rename, move, upgrade, downgrade

ルール：
- 小文字で書くこと
- タイプは主語の動詞で、説明がそれを一文にまとめる。命令形を維持 ("add" ではなく "added")
- 説明を二つ目の動詞で始めないこと: "fix the footer wrapping" ではなく "fix stop the footer from wrapping"
- 1 回のコミットにつき、1 つの論理的な変更
````
